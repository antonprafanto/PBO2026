# Materi 01 — Pengantar Pemrograman Berorientasi Objek

## 🎯 Tujuan Pembelajaran

Setelah mengikuti materi ini, mahasiswa mampu:
1. Menjelaskan apa itu Pemrograman Berorientasi Objek (OOP) dan perbedaannya dengan paradigma prosedural
2. Mendefinisikan konsep **Kelas**, **Objek**, **Atribut**, dan **Method**
3. Menyebutkan dan menjelaskan singkat **4 Pilar OOP**
4. Membuat kelas sederhana dan objek pertama menggunakan Python

## 🔑 Kata Kunci Penting

| Istilah | Arti |
|---------|------|
| `class` | Kata kunci Python untuk mendefinisikan kelas |
| `object` / instance | Wujud nyata yang dibuat dari kelas |
| `__init__` | Konstruktor — dijalankan otomatis saat objek dibuat |
| `self` | Referensi ke objek itu sendiri |
| atribut | Data/sifat yang dimiliki objek |
| method | Fungsi yang dimiliki oleh kelas |
