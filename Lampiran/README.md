> Lampiran berisi bahan pendukung yang bisa kamu buka kapan saja selama semester: kamus istilah, contekan sintaks dua bahasa, daftar bacaan, dan jawaban atas pertanyaan yang sering muncul.

| Lampiran | Isinya | Kapan dibuka? |
|---|---|---|
| [Glosarium](glosarium.md) | istilah PBO dari A sampai Z, padanan bahasa Inggrisnya, arti singkat, dan pertemuan yang membahasnya | saat lupa arti sebuah istilah |
| [*Cheat Sheet* Python ↔ Java](cheatsheet-python-java.md) | sintaks penting Python dan Java berdampingan, dari Pertemuan 01 sampai 15, dengan contoh bertema KedaiKita | saat lupa cara menulis sesuatu, atau saat membaca kode di jalur lain |
| [Referensi](referensi.md) | buku, dokumentasi resmi, situs belajar, dan alat bantu | saat ingin memperdalam materi |
| [FAQ](faq.md) | pertanyaan yang sering diajukan: memilih jalur, solusi yang berbeda, penggunaan AI, melaporkan kesalahan, versi Python dan Java | saat ragu tentang cara belajar di mata kuliah ini |

Masalah instalasi dan pesan *error* saat menjalankan program dibahas terpisah di [00-Persiapan: Mengatasi Masalah](../00-Persiapan/mengatasi-masalah.md).
