# Pertemuan 03 — Atribut dan Method

## 🎯 Tujuan Pembelajaran

Setelah mengikuti pertemuan ini, mahasiswa mampu:
- Membedakan **atribut instance** vs **atribut kelas**
- Membedakan **method instance**, **class method**, dan **static method**
- Menggunakan decorator `@classmethod` dan `@staticmethod` dengan tepat
- Memilih jenis atribut dan method yang sesuai dengan kebutuhan

---

## 📋 Ringkasan Materi

| Topik | Deskripsi |
|-------|-----------|
| Atribut Instance | Data unik per objek (via `self`) |
| Atribut Kelas | Data yang dibagi semua objek |
| Method Instance | Akses `self` → data per objek |
| Class Method | Akses `cls` → data kelas |
| Static Method | Independen dari kelas/objek |
