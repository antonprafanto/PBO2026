## 2. Cara Membuka dan Mengunduh

- **Membaca tanpa mengunduh:** klik tautan **📄 PDF**. GitHub menampilkan PDF langsung di *browser*, jadi cocok dibuka dari HP.
- **Mengunduh satu berkas:** klik tautan **⬇️ PowerPoint** (atau PDF), lalu klik tombol **Download raw file** (ikon panah ke bawah) di kanan atas halaman berkas.
- **Mengunduh semuanya sekaligus:** unduh seluruh repositori lewat tombol **Code** › **Download ZIP** di halaman utama repositori. Semua *slide* ada di folder `Slide/`.
- **Membuka berkas PowerPoint:** pakai Microsoft PowerPoint, Google Slides (unggah dulu ke Google Drive), atau LibreOffice Impress yang gratis.

## 3. Cara Memakai *Slide* untuk Belajar

- **Sebelum kuliah:** lihat sekilas *slide* tujuan dan agenda supaya kamu tahu arah pertemuan.
- **Sesudah kuliah:** buka halaman materi lengkap di folder pertemuan. *Slide* hanya ringkasan; penjelasan utuh, kode lengkap yang bisa dijalankan, latihan, dan kuis ada di sana.
- **Kuis Cepat:** setiap *slide* kuis langsung diikuti *slide* jawabannya. Jawab dulu dalam hati sebelum pindah ke *slide* berikutnya.
- **Catatan pembicara** (*speaker notes*) berisi penjelasan untuk setiap *slide*. Di PowerPoint, buka lewat menu **View** › **Notes**. Di PDF, catatan ini tidak ikut tercetak.
- **Kode di *slide* adalah potongan.** Baris yang dilompati ditandai komentar abu-abu `# ...` (Python) atau `// ...` (Java). Untuk mencoba kode, salin dari berkas di folder `python/` atau `java/` pertemuan itu, bukan dari *slide*.

## 4. Catatan Teknis

- Ukuran *slide* 16:9 dengan huruf Calibri dan Consolas, yang tersedia di Windows dan Microsoft Office. Di Google Slides atau LibreOffice, huruf penggantinya bisa membuat beberapa baris sedikit bergeser.
- PDF dibuat dari berkas PowerPoint yang sama, jadi isinya identik.
- Jika isi *slide* berbeda dengan halaman materi, yang berlaku adalah halaman materi. Temukan kesalahan? Laporkan dengan cara di [Beranda](../README.md#12-menemukan-kesalahan).
- Gambar ilustrasi di *slide* berasal dari folder `gambar/` setiap pertemuan. Sumber dan lisensinya tercantum di [Referensi bagian 8](../Lampiran/referensi.md#8-sumber-gambar).
