## 🚀 Cara Menggunakan Repositori Ini

### 1. Clone Repositori
```bash
git clone https://github.com/antonprafanto/PBO2026.git
cd PBO2026
```

### 2. Pastikan Python Terinstall
```bash
python --version  # Minimal Python 3.8+
```

### 3. Jalankan Contoh Kode
```bash
cd Materi_01_Pengantar_OOP/kode
python 01_prosedural_vs_oop.py
```

### 4. Kerjakan Latihan
```bash
python latihan.py  # Baca petunjuk di dalam file
```
